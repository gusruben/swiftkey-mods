# SwiftKey Mods

ReVanced patches for Microsoft SwiftKey 9.13.17.6, including two-finger swipe typing.

## Demo

https://github.com/user-attachments/assets/d857e328-c3e5-49da-bb52-4c155ee77e9a

## Install

1. Download the SwiftKey 9.13.17.6 APK from a site like [APKMirror](https://www.apkmirror.com/apk/swiftkey/swiftkey-keyboard/microsoft-swiftkey-ai-keyboard-9-13-17-6-release/)
2. In ReVanced Manager, add `https://github.com/gusruben/swiftkey-mods/releases/latest/download/patches-bundle.json` as a patch source.
3. Patch the APK and install it.
4. Find the settings in SwiftKey's settings under Mods.

## Patches

| Patch | What it does |
|---|---|
| Two-finger swipe | Adds a setting + toolbar button to enable two-finger swipe-to-type. The engine is based on [Nintype](https://apps.apple.com/us/app/nintype/id796959534) |
| Rainbow swipe trail | Adds a setting to make the swipe trail rainbow |
| Key press ripple | Adds a setting for a rainbow key press effect |
| Watermark key hints | Adds a setting to restyle the long-press symbols hints (see video demo) |
| Capital I toggle | Adds a setting + toolbar button to stop autocorrecting "i" to "I" |
| Hide space bar branding | Removes the Microsoft SwiftKey wordmark from the space bar |
| Disable tracking | Turns off Adjust and Firebase Crashlytics |
| Enable backups | Lets Android back up settings and learned words |
| Install alongside original | Installs separately from stock SwiftKey as "SwiftKey (modded)"; on by default |
